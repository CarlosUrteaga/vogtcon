# Repository Instructions

## Pull request language

- Write all pull request titles and descriptions in English, including headings, tables, checklists, and validation notes.
- Use English for new pull request comments and review summaries.
- When updating a pull request, translate non-English author-written prose while preserving its meaning, code, identifiers, paths, links, and evidence.
- Preserve reviewer-owned content, checkbox states, and recorded approvals. Do not claim reviews or test results that were not verified.
- Use the user's preferred language in chat. Repository documentation may retain its established language.
